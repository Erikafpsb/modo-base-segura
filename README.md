# Modo Base Segura

Modo — Parte 1: Base e autenticação

No projeto existente, implemente somente a base do Modo. Não recrie páginas ou componentes que já funcionam. Não use IA nem adicione tarefas, calendário, Premium ou pagamentos nesta etapa.

Visual: design moderno, responsivo e em português brasileiro, reutilizando os estilos existentes.

Supabase: reutilize o projeto atual. Não crie outro banco ou serviço.

Cadastro: nome, e-mail e senha.

Login: e-mail e senha, recuperação de senha e logout.

Sessão: manter o login ao atualizar a página e proteger o painel.

Painel inicial: mostrar uma saudação e espaços reservados para futuras funcionalidades.

Segurança: não armazenar senhas manualmente. Proteger os dados privados com RLS, para cada usuário acessar apenas os próprios registros.

Economia: realizar apenas as alterações necessárias, reutilizando configurações e componentes existentes.

Teste cadastro, login, logout, recuperação de senha e proteção do painel. A autenticação deve funcionar de verdade com Supabase, não ser apenas visual.

Ao terminar, não implemente as próximas etapas.
